#  Overview

The **AI Student Performance Analysis System** is an intelligent educational platform that uses:

- Machine Learning
- Artificial Intelligence
- Data Analytics
- LLM Integration

to analyze student academic performance, estimate stress levels, and generate personalized recommendations.

The system helps teachers and institutions identify weak students early and improve learning outcomes through predictive analytics.

#  Features

##  Student Performance Prediction
- Predicts academic performance using Machine Learning models.

##  AI Chatbot
- Ask questions related to student analytics and recommendations.

##  Stress & Mental Stability Analysis
- Detects stress indicators using behavioral and academic patterns.

##  Analytics Dashboard
- Interactive charts and performance trends.

##  PDF Report Generation
- Automatically generates detailed reports.

##  Email Automation
- Sends reports to students, teachers, or parents.

##  Personalized Recommendations
- AI-generated suggestions for academic improvement.
